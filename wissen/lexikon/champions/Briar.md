# Briar

Stand: Patch 26.19 (Data Dragon 16.19.1), 26.09.2026. CDs aus Data Dragon.

## Kopf
- Name: Briar, der gebändigte Hunger. Rollen: Dschungel. Klasse: Kämpferin/Assassine (Data Dragon: Fighter, Assassin). Ressource: Zorn (Leben als Kosten).
- Spielidee: Blutrausch-Dive. Im Rausch (W) greift sie automatisch das nächste Ziel an und heilt stark; ihre R fliegt über die halbe Karte auf das erste getroffene Ziel.

## Faehigkeiten-Kniffe
- Passiv Blutroter Fluch: Angriffe/Fähigkeiten lassen Gegner bluten; sie heilt mehr, je weniger Leben sie hat, aber verliert Heilung von außen teilweise.
- Q Hals über Kopf: Sprung 475 auf ein Ziel, kurzer Stun, senkt Resistenzen. CD 13/12/11/10/9.
- W Blutrausch / Heißhunger: Sprung + Rausch – sie kann NICHT mehr frei wählen, greift das nächste Ziel an, bekommt Angriffstempo. Reaktivierung: Biss mit Heilung. CD 14/13/12/11/10.
- E Blutrünstiger Schrei: Kanalisierung (Schadensreduktion), Loslassen = Welle; voll geladen stößt zurück, an einer Wand Stun. CD 16.
- R Sicherer Tod: Kopf-Projektil sehr weit (12000); trifft den ersten Champion, sie fliegt hin, Furcht auf Gegner nahe der Landung, danach Rausch. CD 120/100/80.
- Combo: W (Rausch) → Q (Stun) → Biss-Heilung; oder R auf markiertes Ziel → Q → W.
- Zeichen: Rausch-Aura = sie läuft auf das nächste Ziel, Richtung vorhersehbar.

## Powerspikes
- Level 3 Ganks; Level 6 R (Karten-Dive). Items mit Lebensraub/Tempo.
- Schwächen: Heilungsreduktion; harter CC im Rausch; Kiten.

## Lane-Plan
- Dschungel: schneller Clear, frühe Ganks auf Lanes ohne Flucht.
- Gank-Muster: W-Sprung aus Gras, Q-Stun; ab 6 R aus dem Nebel über Kartenteile.

## Gegen diesen Champion
- Im Rausch lenkbar: einen Tank/Vasallen zwischen sie und den Carry stellen – sie greift das Nächste an.
- Harter CC stoppt den Rausch; danach bursten.
- Heilungsreduktion früh (sie lebt von Heilung).
- R-Projektil ist lang sichtbar: seitlich ausweichen oder einen Verbündeten/Vasallen davor lassen; nach Landung Furcht → Abstand halten.
- E voll geladen: nicht mit dem Rücken zur Wand stehen.
- Ohne R (80–120 s) keine Fernbedrohung.

## Makro/Teamfight
- Dive auf Backline; stark in unübersichtlichen Kämpfen, schwach gegen Peel.
- Objectives: mittel.

- typische Kern-Items (ungeprüft): Eklipse, Gespaltener Himmel, Steraks Pegel.
